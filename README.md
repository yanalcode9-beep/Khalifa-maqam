# مَقام | Maqam
موقع تفاعلي ثنائي اللغة لمساق **«مدخل إلى علم الموسيقا»** — جامعة النجاح الوطنية، **بإشراف الدكتور خليفة جاد الله**.
تصميم وبرمجة: **ينال أبو لاوي**.

موقع ستاتيك خالص (HTML/CSS/JS بدون أي فريموورك أو build). يبدأ **فاتح وعربي** افتراضيًا، وكل الأصوات مولّدة بـ Web Audio ما عدا غناء أسماء النوتات (تسجيلات بشرية — شوف الرخص تحت).

---

## شو في بالريبو
```
shared/            ← المصدر الوحيد للمحتوى والصوت والأدوات (عدّل هون)
site/              ← الموقع نفسه (هاد اللي بينرفع)
  index.html       ← الصفحة + الميتا + JSON-LD
  css/ js/         ← ستايل وسكربتات الموقع (maestro.js = قسم المشرف والتقسيمة)
  shared/          ← نسخة من shared/ (بتتعمل تلقائيًا)
  assets/          ← صورة الدكتور (بدون خلفية) + og.jpg + الأيقونات
  sitemap.xml robots.txt 404.html manifest.webmanifest
scripts/
  sync.sh          ← ينسخ shared/ → site/shared/
  set-domain.sh    ← يحط الدومين الحقيقي بدل maqam.example.com
.github/workflows/deploy-site.yml ← نشر تلقائي على GitHub Pages
```

## التشغيل محليًا
```bash
./scripts/sync.sh
cd site && python3 -m http.server 8080   # افتح http://localhost:8080
```

## النشر
**قبل أي نشر:** حط الدومين الحقيقي (مهم جدًا للـ SEO — الـ canonical والـ sitemap والـ og:image لازم تكون روابط حقيقية):
```bash
./scripts/set-domain.sh https://your-domain.com
```

- **GitHub Pages:** ارفع الريبو، من Settings → Pages اختار Source = GitHub Actions. كل push على `main` بينشر `site/` تلقائيًا.
- **Vercel / Netlify:** مشروع جديد من الريبو، Root Directory = `site`، بدون build command.

## الظهور على Google (SEO)
الموقع جاهز من جوّا: عنوان ووصف بالعربي والإنجليزي، canonical + hreflang، Open Graph/Twitter، بيانات منظّمة JSON-LD (الموقع، الجامعة، الدكتور خليفة جاد الله كـ Person، المساق، أسئلة شائعة)، sitemap فيه الصور، ونص حقيقي قابل للفهرسة بالقسمين «عن الموقع» و«المشرف».

بعد النشر:
1. ادخل [Google Search Console](https://search.google.com/search-console) → Add property → دومينك، وأكّد الملكية (DNS أو ملف HTML بتحطه بـ `site/`).
2. Sitemaps → اكتب `sitemap.xml` → Submit.
3. URL Inspection → الصفحة الرئيسية و `?lang=en` → Request indexing.
4. نفس الشي على [Bing Webmaster Tools](https://www.bing.com/webmasters) (بتستورد من Search Console بكبسة).
5. أقوى شي فعليًا: **روابط من مواقع موثوقة** — رابط من صفحة الدكتور على موقع النجاح أو صفحة القسم، ومشاركة الرابط بمجموعات الطلاب.

> ملاحظة صادقة: Google بيتجاهل وسم `keywords`. اللي بيرفع الترتيب هو الدومين الحقيقي + المحتوى الظاهر + الروابط الخارجية + الوقت. ما في أحد بيقدر يضمن المرتبة الأولى.

## إضافة لحن لـ«خمّن اللحن»
بـ `shared/content.js` → `MQ.melodies`. النوتات بصيغة `"C4"`, `"F#4"`, `"Bb3"`، وربع التون `"Ehf4"` (مي نص بيمول) و `"Bhf4"`. القالب والتعليمات موجودة فوق المصفوفة. **ضيف اللحن بس بعد ما موسيقي يراجع نوتاته.** بعدين `./scripts/sync.sh`.

## «دوّن لحنك» — إضافة ألحان من الموقع نفسه
تحت لعبة «خمّن اللحن» في محرّر: تضغط النغمات على البيانو (أو تلصق التدوين نصًا مثل `صول/.75 صول/.25 لا صول دو5 سي/2`)، تختار مدة كل نغمة وربع التون، تسمّي اللحن وتحفظه.
- اللحن المحفوظ يُغنّى فورًا ويدخل في أسئلة اللعبة (ومعه خيار «ألحاني» لتخمين ألحانك فقط).
- الحفظ في متصفح المستخدم نفسه (localStorage)، فما في سيرفر ولا قاعدة بيانات.
- **رابط التحدي:** كل لحن إله رابط فيه اللحن مشفّر (`?m=...#guess`). أي حدا بيفتحه بيطلعله اللحن كسؤال «تحدٍّ من صديق»، ويقدر يحفظه عنده.
- **لإضافته للموقع للجميع:** زر «انسخ الكل ككود للموقع» بيعطيك سطر جاهز تلصقه داخل `MQ.melodies` في `shared/content.js`، ثم `./scripts/sync.sh`.
- الأمان: كل لحن (محفوظ أو من رابط) بيتفحص قبل الاستخدام (صيغة النوتات، الطول، السرعة)، والأسماء بتنعرض كنص فقط.
